# ImpulseTech Frontend (`impulsetech-fe`)

Frontend SPA para la plataforma operativa y CRM de ImpulseTech, desarrollado en Angular 18+ con Standalone Components, Signals y Tailwind CSS, bajo las directrices estrictas de la skill `frontend-design`.

## Requisitos
- Node.js 20+ / 22+
- npm 10+
- Docker

## Ejecución Local
```bash
# Con Docker Compose desde la raíz
docker compose up frontend

# O de forma independiente
npm install
npm start
```
La aplicación estará disponible en `http://localhost:4200`.

## Compilación para Producción
```bash
npm run build
```
